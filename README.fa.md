# Penguin Ops — وب‌سایت بازی‌محور رضا بجنوردی

این پروژه فقط با HTML، CSS و JavaScript ساخته شده است. برای اجرا به سرور اختصاصی، بک‌اند، نصب پکیج، کلید API یا مرحلهٔ build نیاز ندارد. فایل‌ها و فونت‌ها محلی هستند و بازی بدون وابستگی به CDN اجرا می‌شود.

## اجرای سریع

در سورس پروژه، `dist/index.html` را در مرورگر باز کن. در بستهٔ آمادهٔ GitHub Pages، همین `index.html` در ریشهٔ فایل ZIP قرار دارد؛ بسته را از حالت فشرده خارج کن و آن را باز کن.

## انتشار روی GitHub Pages

۱. در گیت‌هاب یک repository بساز یا مخزن دلخواهت را انتخاب کن.

۲. **محتویات بستهٔ ZIP** را در ریشهٔ مخزن قرار بده. اگر از سورس پروژه استفاده می‌کنی، **محتویات پوشهٔ dist** را منتقل کن. خود پوشهٔ `dist` را به‌عنوان پوشهٔ اضافی آپلود نکن. `index.html`، فایل‌های JavaScript و CSS، فایل `.nojekyll` و پوشهٔ `assets` باید کنار هم باشند. نام فایل‌ها را تغییر نده.

۳. به **Settings → Pages → Build and deployment** برو.

۴. گزینهٔ **Deploy from a branch** را انتخاب کن. شاخه را **main** و پوشه را **/ (root)** بگذار و Save را بزن. اگر شاخهٔ تو نام دیگری دارد، همان شاخه را انتخاب کن.

۵. بعد از پایان انتشار، آدرس سایت در همان صفحهٔ Pages نمایش داده می‌شود.

مسیر فایل‌ها نسبی است؛ بنابراین هم در دامنهٔ اصلی GitHub Pages و هم در زیرمسیر یک مخزن اجرا می‌شود. هیچ GitHub Actions سفارشی لازم نیست. فایل `.nojekyll` را نگه دار تا Jekyll فایل‌ها را پردازش نکند. ساخت مخزن و انتشار در حساب گیت‌هاب تو به‌صورت خودکار انجام نشده است.

راهنمای رسمی: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## نسخهٔ جدید: رالی شمالی

جزیره بزرگ‌تر شده و یک جادهٔ ساحلی حلقه‌ای، تعمیرگاه، موتور با پنگوئن کلاه‌کاسکت‌دار، سه رمپ پرش، موانع ثابت، مخروط‌های قابل هل‌دادن، دریاچهٔ یخ‌زده و ۲۴ تراشهٔ قابل جمع‌کردن دارد. می‌توانی پیاده یا با موتور به شش ایستگاه رزومه سر بزنی. مسابقهٔ زمان‌دار را شروع کن و به‌ترتیب از هشت دروازهٔ مشخص‌شده عبور کن. بهترین رکورد و تراشه‌ها در همین مرورگر ذخیره می‌شوند؛ جدول امتیاز آنلاین یا مشترک وجود ندارد.

موتور شتاب، فرمان، دنده‌عقب، ترمز، بوست شارژی و برخورد دارد. از روی رمپ با سرعت بگذر تا بپری. کنترل پیاده نسبت به دوربین است؛ روی موتور، چپ و راست فرمان می‌دهند و بالا/پایین گاز و دنده‌عقب هستند. کلیک روی زمین، نقشه یا ایستگاه، حرکت خودکار را شروع می‌کند و با کلیدهای حرکت کنترل را دوباره می‌گیری.

## سناریوی بازی

شبکهٔ شمالی پس از یک قطعی داستانی از دسترس خارج شده است. «پیپ»، پنگوئن کنجکاو و عاشق لینوکس، باید شش ایستگاه را دوباره وصل کند. هر ایستگاه بخشی از مسیر شغلی رضا را نشان می‌دهد:

| ایستگاه | بخشی از رزومه |
|---|---|
| اردوگاه ترمینال | لینوکس، مدیریت سیستم و برنامه‌نویسی بک‌اند |
| بندر کلاد | OpenStack، Ceph، کلاد چندمنطقه‌ای و زیرساخت GPU |
| بلندی ولیدیتورها | زیرساخت بلاک‌چین، نودها، ارتقا و همگام‌سازی |
| باغ اتوماسیون | Ansible، Terraform و فرایندهای استقرار |
| رصدخانه | پایش، قابلیت اطمینان و عیب‌یابی |
| قلهٔ دانش | تحصیلات، یادگیری و انتقال تجربه |

حل هر مأموریت کوتاه، یک ایستگاه را روشن می‌کند؛ پس از تکمیل هر شش مرحله، برج ارتباطی مرکزی روشن می‌شود. مأموریت‌ها داستانی‌اند. رزومه و اطلاعات حرفه‌ای از دو فایل رزومهٔ ارائه‌شده آمده‌اند. برای دیدن رزومه نیازی به بازی یا حل مأموریت‌ها نیست.

روی موبایل، دکمه‌های حرکت، پرش، بوست، ترمز و موتور، نقشهٔ کوچک و فهرست بازشوندهٔ ایستگاه‌ها وجود دارند. تغییر بین دو نما موقعیت پنگوئن و پیشرفت مرحله‌ها را حفظ می‌کند. با دکمهٔ زبان، رابط و رزومه بین فارسی و انگلیسی تغییر می‌کنند.

## تغییر محتوا

اطلاعات شغلی، مهارت‌ها، راه‌های تماس و متن هر دو زبان در `content.js` قرار دارند. متن صفحهٔ اصلی در `index.html` است. برای عوض‌کردن رزومه‌های دانلودی، PDFهای داخل `assets` را جایگزین کن. گواهی CKA در محتوا «پایان دوره» معرفی شده است، نه قبولی آزمون؛ پیوند گواهی‌ها از PDFهای اصلی برداشته شده و وضعیت فعلی آن‌ها مستقلاً بررسی نشده است.

مدل‌های سه‌بعدی با مختصات واقعی XYZ در JavaScript ساخته و با یک رندرکنندهٔ نرم‌افزاری روی Canvas نمایش داده می‌شوند. بنابراین WebGL لازم نیست. این نسخه یک بازی سبک و سبک‌پردازی‌شده است؛ موتور فیزیک کامل ندارد. مدل‌ها، نقشه و کد از سایت مرجع کپی نشده‌اند.

زبان و پیشرفت، در صورت پشتیبانی مرورگر، در `localStorage` همان مرورگر ذخیره می‌شوند و بین دستگاه‌ها همگام نمی‌شوند. از راهنمای بازی می‌توان پیشرفت را بازنشانی کرد. قطعهٔ بی‌کلام ۹۶ ثانیه‌ای «نورهای شمالی» با اولین کلیک روی ورود به بازی شروع و به‌صورت تکرارشونده پخش می‌شود. دکمهٔ آهنگ پخش را متوقف یا ادامه می‌دهد. با نگه‌داشتن نشانگر یا فوکوس روی دکمه، تنظیم بلندی صدا نمایش داده می‌شود. انتخاب قطع صدا و بلندی آن ذخیره می‌شود. با رفتن به تب دیگر، موسیقی موقتاً متوقف می‌شود. حرکت‌های محیط را می‌توان متوقف کرد. هیچ آنالیتیکس، فونت خارجی یا API در زمان اجرای بازی فراخوانی نمی‌شود.

کنترل‌های اصلی و مسیر شش ایستگاه در Chromium بررسی شده‌اند. نسخهٔ فارسی و چیدمان موبایل در قاب ۳۹۰×۸۴۴ پیکسل بررسی شده‌اند؛ آزمایش روی گوشی فیزیکی انجام نشده است.

## بررسی فنی

فایل‌های `tests/game-core.test.cjs` و `tests/world.integration.cjs` با Node.js اجرا می‌شوند. شتاب، ترمز، بوست، برخورد بدون عبور از مانع، پرش از رمپ، مسیر واقعی هر شش ایستگاه، یک دور کامل هشت‌دروازه‌ای، ذخیرهٔ رکورد و رابط فارسی را بررسی می‌کنند. این فایل‌ها برای اجرای خود سایت لازم نیستند.
